# NovaEarn MVP

Private prototype for an investment-platform interface.

## Important
This version is a **prototype only**. It does not process real deposits, real withdrawals, or real investment returns. Do not connect public users or real money until the business model, legal structure, compliance/KYC/AML, custody and required Nigerian registrations have been reviewed.

## Run on Windows

1. Install Python 3.11+.
2. Open CMD in this folder.
3. Run:
   `py -m pip install -r requirements.txt`
4. Run:
   `py app.py`
5. Open:
   `http://127.0.0.1:5000`
